# ERA Framework

## Name
Expectation-Role-Action

## Structure
- **Expectation**: Goal to be achieved
- **Role**: Role the AI plays
- **Action**: Specific tasks to be performed

## Use Cases
- Quick prompt building
- Simple task instructions
- Daily AI interactions
- Lightweight content generation
- Beginner onboarding
- Rapid prototype testing

## Example
**Input**: "Help me write code"

**Optimized**:
```
Expectation: Generate a runnable Python function that can calculate the Fibonacci sequence
Role: You are an experienced Python developer
Action: Write a fibonacci function with type hints and a docstring, including error handling
```

## Usage Tips
- Clarify the goal first, then define the role, and finally describe the task
- Best suited for simple tasks with a clear objective
